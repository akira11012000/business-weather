# ビジネス天気予報

場所と時間帯を指定して、4つの気象モデルの予報を比較できる業務向けの天気アプリです。降雨量・日射量・天候を30分ごとに表示します。

**アプリを開く**：https://akira11012000.github.io/business-weather/

スマートフォンでは、ブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように使えます。

## 主な機能

- **場所の指定**：住所（市区町村＋地区）または施設名で検索。最近見た場所は8件まで残ります。
- **時間帯の指定**：初期表示は8時〜17時。0時〜23時の範囲で変更できます。
- **30分ごとの予報**：最大7日先まで、30分刻みで表示します。
- **3つの表示切り替え**
  - 降雨量（mm／30分、合計・雨の時間・最大値）
  - 日射量（W/m²、平均・最大・積算 kWh/m²）
  - 天候（快晴・晴天・曇り・雨の4区分と、それぞれの時間数）
- **4モデル比較**：気象庁・ヨーロッパ（ECMWF）・アメリカ（GFS）・ドイツ（ICON）の予報を並べて表示します。
- **予報の信頼度**：4モデルの結果がそろっているほど高く表示します。
- **的中実績**：直近8日間について、各モデルの前日・2日前の予報と、最寄りのアメダスの実測を比較します。
- **雨雲の動き**：指定地点の周囲約100km四方の雨雲予報を、24時間先まで地図で表示します。

## 判定の条件

- 30分値：Open-Meteoの15分ごとの予報データから作成（提供がない場合は1時間データを補間）
- 雨あり：30分で0.3mm以上（表の強調表示）
- 天候：雨＝30分で0.1mm以上／快晴＝雲量15%未満／晴天＝雲量85%未満／曇り＝雲量85%以上
- 的中実績：7〜17時の1時間値で比較。予報0.3mm以上、実測0.5mm以上を「雨」とみなします

※天候の区分は本アプリ独自の目安であり、気象庁が発表する天気予報の区分とは一致しません。

## データの出典

- **予報データ**：[Open-Meteo](https://open-meteo.com/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）
  - 元データ：気象庁、ヨーロッパ中期予報センター（ECMWF）、アメリカ海洋大気庁（NOAA/NCEP）、ドイツ気象局（DWD）
- **実測データ**：[気象庁 アメダス](https://www.jma.go.jp/bosai/amedas/)（出典：気象庁ホームページ）
- **場所の検索**：[OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/)（© OpenStreetMap contributors, ODbL）、[国土地理院 住所検索](https://msearch.gsi.go.jp/)
- **地図**：[地理院タイル（国土地理院）](https://maps.gsi.go.jp/development/ichiran.html)
- **地図表示**：[Leaflet](https://leafletjs.com/)（BSD 2-Clause License）
